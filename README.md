# Arc Analytics Explorer

A real-time blockchain explorer and analytics dashboard for Arc Testnet.

## Features

* Live Arc Testnet statistics
* Latest block tracking
* Active wallet analytics
* Wallet search
* Wallet balance lookup
* Recent transactions
* Recent blocks explorer
* Arcscan integration

## Tech Stack

* Next.js 15
* TypeScript
* Tailwind CSS
* viem
* Arc Network RPC

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Mahmoud514/Arc-Analytics-Explorer.git
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
